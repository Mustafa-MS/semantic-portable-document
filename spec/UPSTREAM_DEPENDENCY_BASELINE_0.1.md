# Format 0.1 upstream dependency baseline

Normative maintenance policy, reviewed 2026-09-04. “N” means normative only in the role stated; “I” means informative. Direct dependencies are incorporated by SPD; transitive ones apply through the pinned EPUB publication contract. Neither an implementation library version nor an inspection date is an immutable standards snapshot.

Every row uses the same update policy: future editions, living changes and errata do **not** silently alter SPD 0.1. Adoption requires an explicit SPD maintenance decision, recorded clause differences, impact review, corpus updates and independent validator reconvergence. Unknown/contradictory inherited predicates require clarification, not an invented PASS. EPUB 3.4 is monitored future work only.

Living-reference policy deliberately records the reviewed baseline without fabricating immutable snapshots. This is a governed baseline, not a claim that all transitive standards are byte-frozen. New ambiguous syntax or a tool/spec discrepancy must be resolved through maintenance before being counted as conformance evidence.
